# rtx4080s-unlock — Windows · RTX 4080 SUPER · 32GB 改装卡

**面向 Windows 下 RTX 4080 SUPER 32GB 显存改装卡（`10de:2702`）的 Tensor Core 解锁研究。**

本项目聚焦 **Windows + RTX 4080 SUPER + 32GB 显存改装** 这一细分组合。贡献在于该板卡的 UEFI 适配、带校验的开机自动执行流程、恢复控制及公开验证记录，是基于上游解锁研究开展的细分方案先行探索。

**首创性边界：** 发布准备时的检索未找到同时符合上述三项条件的公开案例。这只是有限检索的结果，不能证明“全球首个”，也不能排除更早或尚未公开的工作。底层解锁技术归功于上游作者。

## 已验证范围

- 一张 **RTX 4080 SUPER**：PCI `10de:2702`、Subsystem `10de:18cc`、AD103 A1，显存扩容至 **32GB**（系统报告 32,760 MiB）。
- Windows 11 Pro、NVIDIA **617.42**、VBIOS `95.03.44.40.74`；实验没有替换 Windows 显卡驱动或刷写 VBIOS。
- Windows 启动前运行 UEFI 程序，执行检查后的固件事务、一次 PCIe FLR、恢复显示并进入 Windows。
- 只有新启动的日志与 Windows CUDA 正确性/吞吐检查通过，才预约下一次 BootNext。
- 本机实测期间 Secure Boot 报告为开启；这不是微软通用签名，也不证明其他主板能接受同一 EFI。

| 测试 | 实测结果 | 范围 |
|---|---:|---|
| v0.6.2 开机健康检查，FP16 输入 / FP32 累加 | 中位数 **196.09 TFLOPS** | 5 次指令微基准，270,336 个输出零误差 |
| FP8 E4M3 / FP32 累加短测 | 中位数 **387.71 TFLOPS** | 256 次循环、3 次采样，输出校验通过 |
| FP8 E5M2 / FP32 累加短测 | 中位数 **387.71 TFLOPS** | 同上 |

这是指令吞吐，不是模型推理速度。公开包没有本卡未解锁 FP8 的同条件基线，不能据此声称实测翻倍。首次 10,000 次循环的 FP8 长累加测试出现数值偏差，原因未明，已保留失败记录。详见[验证与限制](docs/VALIDATION.md)。

## 发布状态

源码版本为 **`0.6.2-public.1`**，本地实测部署为 **`0.6.2`**。

公开版已替换私人磁盘、卷与 GPU 唯一标识。默认构建会拒绝启动分区匹配，Windows 后台也禁止直接安装或执行确认操作；只允许状态读取与离线策略测试。仓库不包含可直接部署的 EFI、ROM、固件镜像或签名密钥。

公开参考构建没有做实机执行验证，其哈希不同于本机已测 EFI。编译、模拟通过不代表兼容；删除检查也不代表适配完成。

## 项目内容

`source/unlock/` 包含 UEFI 应用和事务代码；`host/` 包含后台确认参考实现；`notifier/` 是仅登录时检查的提醒程序；`benchmarks/` 包含微基准源码；`evidence/` 保留成功、模拟与失败记录；`docs/` 提供英文技术文档。

解锁不是永久刷入：本机通过开机前重新应用易失配置实现自动化。它不会增加 CUDA 核心或显存带宽，也不提供专业驱动认证或 vGPU 授权。

此前 WSL GPU 负载期间曾出现 TDR 和 `0x20001 HYPERVISOR_ERROR`。当时观察到显存/系统提交压力，但尚不能排除解锁的影响。短测通过不等于长期稳定。
